rclone AIOS

«rclone AIOS» ist eine private Anwendung für eine einzige Person. Sie überträgt jeden Abend eine verschlüsselte Sicherung von einem privaten Computer in das eigene Google Drive des Betreibers.

Sie verwendet das Open-Source-Programm rclone und hat nur Zugriff auf die Dateien, die sie selbst anlegt (Bereich drive.file). Die Anwendung steht niemandem sonst zur Verfügung.
